# SkyMP

[![Discord Chat](https://img.shields.io/discord/1537522942945001553?label=Discord&logo=Discord)](https://discord.gg/WytBk3GDQv) 

SkyMP is an open-source multiplayer mod for Skyrim!

SkyMP is built on top of [SkyrimPlatform](docs/docs_skyrim_platform.md) - a tool used to create Skyrim mods with TypeScript and Chromium.
